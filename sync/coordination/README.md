# Coordination Files

Core synchronization protocols and coordination logic for WILLOW-HVSCMA integration.

## Files
- `sync_protocol.json` - Core sync protocol definitions and rules
- `coordination_schema.json` - Data schema for cross-system coordination
- `sync_commands.py` - Python coordination command handlers

## Protocol Overview
The coordination system manages:
1. Cross-system data synchronization
2. State management and conflict resolution  
3. Automated workflow coordination
4. Error handling and recovery protocols

## Usage
These files define the core protocols used by the WILLOW sync system to coordinate operations between systems.
