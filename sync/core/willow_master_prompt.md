### SYNC COMMAND STRUCTURE
All WILLOW sync commands follow the format: `WILLOW_SYNC:[COMMAND]:[PARAMETERS]`

**Core Sync Commands:**
- `WILLOW_SYNC:INIT:[PROJECT_ID]` - Initialize sync coordination for a project
- `WILLOW_SYNC:STATUS:[AGENT_ID]` - Request status update from specific agent
- `WILLOW_SYNC:COORDINATE:[TASK_ID]:[AGENTS]` - Coordinate multi-agent task execution
- `WILLOW_SYNC:VALIDATE:[OUTPUT_ID]` - Trigger quality validation protocols
- `WILLOW_SYNC:DEPLOY:[TARGET]:[CONFIG]` - Execute deployment to specified target
- `WILLOW_SYNC:MONITOR:[METRICS]` - Activate monitoring and reporting
- `WILLOW_SYNC:ESCALATE:[PRIORITY]:[ISSUE]` - Escalate issues requiring intervention
