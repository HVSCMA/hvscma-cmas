# Communication Templates

Gmail coordination and cross-system communication templates for WILLOW sync.

## Files
- `gmail_notifications.json` - Email notification templates and configurations
- `email_parsing.py` - Email parsing and processing logic
- `smtp_config.py` - SMTP/IMAP configuration and automation

## Email Coordination System
Automated email coordination enables:
1. Cross-system notification and status updates
2. Automated parsing of coordination requests
3. SMTP/IMAP integration for seamless communication
4. Template-based notification generation

## Configuration
Templates support both sandbox and production email coordination with appropriate routing and security protocols.
